# 100억의 선택 — 산업별 경제 파급효과 비교
202311084_경제학전공_나영채
한국은행 2023년 산업연관표(생산자가격)로 동일한 국내 생산물 최종수요가 서로 다른 산업에서 발생할 때의 파급효과를 비교하는 웹앱입니다.


## 사용 방법

1. 사이트를 열면 대분류 자료를 자동으로 읽고 기본 비교를 표시합니다.
2. 중분류·소분류·기본부문으로 바꾸려면 분류 선택 후 **엑셀 다시 불러오기**를 누릅니다. 자료 크기에 따라 잠시 걸릴 수 있습니다.
3. 시나리오별 동일 금액을 입력합니다. 기본값은 **100억 원**입니다.
4. A·B·C에서 산업을 선택합니다. **산업 추가해 나누기**로 각 시나리오에 최대 5개 산업을 넣고 비중 합계를 100%로 맞춥니다.
5. **파급효과 비교하기**를 누릅니다. 입력을 바꾸면 이전 결과가 숨겨지므로 다시 계산해야 합니다.
6. 억 원/백만원 표시 단위를 바꾸거나, 결과 CSV를 다운로드하거나, 인쇄에서 PDF로 저장할 수 있습니다.
7. **원자료 탐색**에서 12개 시트와 행·열을 검색할 수 있습니다. 선택 행 CSV는 열 검색 필터와 관계없이 그 행의 전체 열을 내보냅니다.

분류를 바꾸면 산업 범위가 달라지므로 시나리오가 초기화됩니다. 다른 분류의 계수를 섞지 않습니다. 기준연도 국내 생산이 0인 부문은 국산품 수요 시나리오와 순위에서 제외하되 원자료 탐색과 전체 행렬에는 유지합니다.

## 로컬 실행

HTML을 더블클릭하는 `file://` 방식에서는 브라우저가 Excel fetch와 Worker 실행을 제한합니다. Python이 설치되어 있다면 `index.html`이 있는 폴더에서 아래 명령을 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 종료는 터미널에서 Ctrl+C입니다. Python이 없어도 GitHub Pages에서는 실행할 수 있습니다.

## 분석 방법

Δf: 국내 생산물 최종수요 증가 벡터. Ad: 국산투입계수. Am: 수입투입계수. v: 산업별 부가가치율.

```text
L = (I − Ad)^(-1)
Δx = L Δf                   생산유발액
Δm = Am L Δf = M Δf         수입유발액
Δv = diag(v) L Δf = V Δf    부가가치유발액
```

브라우저는 원본의 생산·수입·부가가치 유발계수 행렬을 사용합니다. 불러올 때 `(I−Ad)L=I`, `AmL=M`, `diag(v)L=V`를 검사하고 최대 절대 잔차가 `1e-8` 이상이면 계산을 차단합니다. 행은 효과가 발생하는 산업, 열은 최초 수요가 발생하는 산업입니다.

내부 계산과 CSV의 단위는 **백만원**입니다. **1억 원 = 100백만원**, **100억 원 = 10,000백만원**입니다. 화면에서만 표시값을 반올림하며 계산에 쓰는 값은 반올림하지 않습니다. 같은 산업을 여러 번 선택하면 수요를 합산합니다.

‘연쇄 생산’은 `Δx − Δf`로, 최초 최종수요 외에 추가로 필요한 생산입니다. 해당 산업 자체의 중간재 생산도 포함합니다. 생산유발배수는 생산유발액을 최초 최종수요 증가액으로 나눈 값입니다.

## 결과 해석과 한계

- 생산유발액은 중간재 거래를 포함하므로 GDP 증가액과 다릅니다.
- 부가가치에는 임금·영업잉여·고정자본소모·생산세 등이 포함됩니다. 기업 순이익이나 투자수익률이 아닙니다.
- 세 지표를 더하면 중복 집계가 생깁니다. 따로 비교해야 합니다.
- 수입유발액은 국내 생산에 필요한 수입 중간재입니다. 수입 완제품을 직접 사는 금액은 입력에서 제외합니다.
- 입력은 국산품 최종수요 증가액입니다. 보조금, 예산 배정액을 그대로 동일시하지 않습니다.
- 2023년 고정 투입구조와 선형 관계, 고정 가격, 공급 가능성을 가정합니다. 공급 제약·가격 변화·재원 조달·다른 지출 감소·추가 가계소비는 반영하지 않습니다.
- 분류마다 평균적 투입구조가 달라집니다. 분류 수준을 바꾸어도 같은 결과가 보장되지는 않습니다.
- 생산유발액이 높거나 수입유발액이 낮다는 것만으로 좋은 산업이나 최적 정책이라고 단정할 수 없습니다.
- 전 산업 순위는 같은 금액을 각 산업에 전부 배분한 독립적인 시나리오입니다. 순위별 결과를 합치지 않습니다.
- 고용유발효과는 별도 고용표가 필요하므로 계산하지 않습니다.

## 기본 비교 예시

대분류에서 컴퓨터·전자·광학기기(A), 건설(B), 정보통신·방송서비스(C)에 각각 국내 최종수요 100억 원이 증가하는 경우입니다.

| 지표(억 원) | A | B | C |
|---|---:|---:|---:|
| 생산유발액 | 171.81 | 205.84 | 167.83 |
| 부가가치유발액 | 57.16 | 79.61 | 83.23 |
| 수입유발액 | 42.84 | 20.39 | 16.77 |

이 세 조건에서는 건설의 생산유발액이 가장 크지만, 정보통신·방송서비스의 국내 부가가치유발액이 더 큽니다. 생산 규모와 국내 부가가치가 서로 다른 지표라는 점을 보여줍니다. 이는 세 시나리오의 비교이며 전 산업 최적 정책 순위가 아닙니다.

## 검증 재현

Node.js가 설치되어 있다면 외부 npm 설치 없이 다음 명령으로 검증할 수 있습니다.

```bash
node tests/engine.test.cjs
```

Python 기준값을 재생성하려면 numpy와 openpyxl이 설치된 환경에서 다음을 실행합니다.

```bash
python scripts/model.py
node tests/engine.test.cjs
```

검증 범위: 4개 분류의 모든 시트, 행렬 정의식, Python 선형시스템 직접해법과 전 산업 결과의 일치, 금액 배수, 비중 합계, 잘못된 입력, 중복 산업 합산, 국내 미생산 부문 제외, 계수 오류 감지.
